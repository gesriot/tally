# tally-rank

Строковые ключи порядка для списков (в духе LexoRank): между любыми двумя ключами всегда можно вставить новый, не трогая соседей.

Ключ – ASCII-строка из алфавита base-62 (`0-9A-Za-z`). Порядок ключей – обычное побайтовое сравнение строк, поэтому `ORDER BY` по колонке `TEXT` в SQLite сортирует так же, как `Rank` в Rust. Схема – дробная индексация (как в `fractional-indexing`): целая часть переменной длины плюс дробная часть.

- Вставка в конец или в начало меняет целую часть; длина растёт логарифмически (тысячи вставок – 3–4 символа).
- Вставка между соседями делит дробную часть пополам; длина растёт примерно на символ за ~6 вставок в одно и то же место. Для таких случаев есть `Rank::spread` – ребалансировка списка.

```sh
cargo run -p tally-rank --example growth   # рост длины ключей при вставках в одно место
cargo test -p tally-rank
```

Тесты: `tests/stress.rs` – тысячи вставок в одно и то же место, ключи остаются строго упорядоченными; `tests/props.rs` – property-тесты на случайных последовательностях вставок и удалений.
